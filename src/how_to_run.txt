HOW TO RUN THE FINAL PROJECT

1. Install Python 3.10 or newer.

2. Install the required packages from the repository root:

   pip install -r requirements.txt

3. Make sure Gurobi Optimizer is installed and licensed.

4. Put the dataset in this location:

   data/marketing_campaign_dataset.csv

5. Run the final experiment from the repository root:

   python src/mmaster_code_experiments.py

6. The generated outputs will be saved under:

   outputs/

Main output files:
   outputs/ga_milp_20run_results.csv
   outputs/ga_milp_20run_scenario_setup.csv
   outputs/ga_vs_milp_20run_comparison.csv
   outputs/ga_milp_20run_method_summary.csv
   outputs/figures/
